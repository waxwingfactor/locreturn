# locreturn

Reconcile an offline translator's JSON return after your source text and local translations have moved on.

**Development in progress.** The first supported release will provide a local, source-aware three-way reconciliation workflow for one flat-JSON locale at a time. Research, input contracts, tests, and independently reviewed implementation are being prepared through pull requests.

This tool is for maintainers who already exchange JSON catalogs outside a translation management system. Weblate, Crowdin, Lokalise, Phrase, Tolgee and BabelEdit are strong alternatives when their broader workflows fit.

MIT licensed. No hosted service or runtime dependency is planned.
